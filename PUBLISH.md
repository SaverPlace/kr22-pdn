# Публикация комплекта на GitHub

## 1. Создайте репозиторий

На GitHub нажмите «New repository», задайте имя, например `kr22-pdn`, и выберите публичный доступ (Public). Используйте ветку `main`. Лицензию автоматически не добавляйте, если ещё не определились с условиями распространения.

## 2. Настройте адрес

В папке `repository` выполните команду, подставив свой логин и имя созданного репозитория:

```bash
python3 configure_repository.py YOUR_GITHUB_LOGIN/kr22-pdn
```

Утилита изменит только адрес репозитория в блокноте и ссылки в README. Имя релиза `v1.0.0`, имя архива и контрольную сумму менять не нужно.

Если не хотите запускать команду, можно настроить вручную:

1. В ячейке загрузки модели блокнота замените `GITHUB_REPOSITORY = ""` на `GITHUB_REPOSITORY = "ваш_логин/имя_репозитория"`.
2. В README замените `YOUR_GITHUB_LOGIN/kr22-pdn` на тот же адрес.

## 3. Загрузите программу

Загрузите содержимое папки `repository` в корень репозитория через «Add file > Upload files». Не загружайте всю внешнюю папку `KR22_GitHub`, архив с весами или служебную папку `work`.

После загрузки в корне должны находиться README, блокнот, `model_manifest.json`, `configure_repository.py` и эта инструкция. Отчёт находится в папке `reports`.

## 4. Опубликуйте модель в Releases

1. Откройте «Releases > Create a new release».
2. Создайте тег `v1.0.0`, целевая ветка `main`.
3. Укажите название, например «Обученная RuBERT для варианта 22».
4. Прикрепите оба файла из соседней папки `release`: `rubert_model_v2.zip` и `SHA256SUMS.txt`.
5. Дождитесь завершения загрузки и нажмите «Publish release». Черновик релиза другим пользователям недоступен.

Архив модели имеет размер около 628 МиБ. Его содержимое и SHA-256 совпадают с исходным архивом, изменено только имя файла. В архиве есть также исходный `training_args.bin`; для распознавания он не используется.

Не распаковывайте и не перепаковывайте архив перед загрузкой: блокнот сверяет его контрольную сумму.

## 5. Проверьте доступ

Откройте репозиторий без входа в свой GitHub-аккаунт и проверьте, что архив релиза доступен для скачивания. Затем откройте блокнот в Colab под другим Google-аккаунтом и выполните все ячейки. Блокнот не должен запрашивать подключение Google Диска.

Результат полной проверки: рассчитаны метрики распознавания и BERTScore, создан `/content/KR22_results.zip`. Повторное обучение не требуется. Если GPU недоступен, расчёт на CPU займёт больше времени.

Для сдачи можно отправить ссылку на репозиторий и сам отчёт. Преподаватель сможет открыть блокнот кнопкой в README.
