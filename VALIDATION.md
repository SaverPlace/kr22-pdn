# Проверка подготовленного комплекта

Дата: 20.11.2026.

Проверка выполнена локально на CPU с предоставленным архивом обученной RuBERT. Для проверки пути Colab `/content` перенаправлялись в рабочую папку. Публикация в GitHub и запуск в новом сеансе Colab ещё не выполнялись.

## Загрузка модели

- Все программные ячейки прошли проверку синтаксиса.
- Содержимое исходного архива модели не изменено. SHA-256, CRC файлов и соответствие размерности классификатора 11 меткам конфигурации проверены.
- Веса и токенизатор успешно загружаются из распакованного архива без Google Диска.
- Проверены успешное скачивание через подставленный HTTP-ответ, отказ при неверном размере и SHA-256, сообщение об отсутствующем релизе, защита путей распаковки и настройка адреса репозитория.
- Скачивание с настоящего адреса GitHub Releases можно проверить после публикации репозитория и релиза.

## Проверка программы

- 212 структурных и морфологических проверок пройдены; проверки согласованности повторов и независимых вызовов пройдены.
- Дополнительные тесты морфологии: 6 из 6.
- Проверочная выборка: 585 текстов и 648 эталонных сущностей.
- Текстов с несовпадением распознавания: 1; известный пропуск имени «Лавра».

| Уровень оценки | Macro F1 | Weighted F1 |
|---|---:|---:|
| Целые сущности | 0,9995 | 0,9992 |
| BIO-разметка токенов | 0,9996 | 0,9999 |

При обезличивании эталонных интервалов всех 585 текстов зарегистрированы 2 ошибки с резервными маркерами: фамилии «Зимбардо» и «Карзая». Успешных резервных морфологических замен по контексту: 12. Результаты согласуются с отчётом.

Алгоритмы распознавания, обезличивания, построения выборки и расчёта метрик сохранены. Изменены загрузка модели, закрепление версии transformers и пояснения по запуску. Версия transformers 4.57.6 совпадает с указанной в конфигурации сохранённой модели. При локальной проверке использовались PyTorch 2.8.0 и pymorphy3 2.0.6.

BERTScore в этой проверке повторно не рассчитывался. Ячейка его расчёта сохранена без изменения и выполняется при полном запуске блокнота в Colab. Ей требуется отдельно скачать `bert-base-multilingual-cased`.
